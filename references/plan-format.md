# 单场景方案格式

把方案保存为 UTF-8 JSON，`version` 为 `2`，`scene` 是一个对象。Agent 默认保存在用户当前工作区的 `output/plan-<id>.json`。参考图片的相对路径以方案所在目录解析；`references` 可省略，最多三张 PNG、JPG 或 WebP，单张不超过 20 MB。参考图会上传给选定服务的图像编辑接口，仅作为风格参照。

```json
{
  "version": 2,
  "main_color": "#246B96",
  "accents": ["#D7EDF0"],
  "brief": "由深蓝与浅冷色联想到辽阔、安静的海洋，没有文字",
  "references": [],
  "scene": {
    "id": "open-water",
    "title": "蓝色海域",
    "description": "开阔海水中一头鲸鱼缓缓游过，水面只有少量简化波纹",
    "composition": "俯视画面，鲸鱼位于右下区域，大片水面留白，波纹轻轻引导视线",
    "palette_use": "主色铺陈大片海水，浅冷色用于稀疏波纹，较深蓝色勾出鲸鱼的简化轮廓"
  }
}
```

`id` 只能用小写字母、数字与短横线。`title` 是成品场景名。Agent 根据本次配色与用户约束自行构思，将环境、主体及可选的天气或动作写入 `description`，将视角、主体比例和留白写入 `composition`，将颜色的具体作用写入 `palette_use`；这三项原样进入提示词。上面的海洋场景仅演示格式，题材和元素均可变化，蓝色也可以启发其他场景。

实际生成默认从本 Skill 的 `examples/` 中选 1–3 张样张，将图片的实际绝对路径写入 `references`，也可使用相对于方案目录的有效路径。用户另提供参考图时优先使用用户图片。上面的空数组用于展示无参考图的格式；用户要求仅使用文字风格时可保留为空。

生成入口为 `generate <plan.json>`，无需 `--scene`。从用户当前工作区根目录运行时，图片与同名记录默认写入该工作区的 `output/`；方案可以放在其他目录，默认输出仍由运行时工作目录决定。`--output-dir <目录>` 可显式覆盖。新创作或修改版使用未占用的场景 `id`，已有结果不会覆盖。

旧 `version: 1` 多场景方案需另存为 `version: 2`，将需要生成的一个场景写入 `scene` 并移除 `scenes`。程序拒绝多场景方案，不会自动批量生成。
