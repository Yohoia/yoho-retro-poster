# 视觉规范

依据本 Skill 的 `examples/` 中 8 张方形样张整理；样张尺寸为 2048×2048 或 3508×3508。它们是风景画面，不包含标题文字或海报边框。

风格上借用中期现代主义（mid-century modern）旅游宣传画与国家公园海报的视觉语言：大色块、简化造型、宽阔留白，以及现代平涂插画与丝网印刷/孔版印刷的质感。样张中的山地题材只是一种内容表现；新画面的环境和景物由本次配色启发，保持系列画风即可。

## 核心语言

- 以大块简化色面组织环境与主体，用轮廓、遮挡和少量色阶建立空间，层次清楚，次要信息少。
- 用不规则但有控制的边缘、硬阴影与少量色阶塑造体积；避免照片质感、复杂线稿和等距 3D。
- 画面保留宽阔留白与清楚的视觉焦点。主体的类型、大小、位置和动静由场景决定；有助于空间和叙事时再安排尺度参照。
- 纹理是细微纸面颗粒或局部喷点，不覆盖主要轮廓。部分样张接近纯色块，纹理不是必需项。
- 对比既可以明快（蓝天与青绿草地），也可以克制（粉红山丘与浅暖天空）。不要强制全系列同一种饱和度。

## 参考构图

现有样张可观察到以下两种构图取向。选择 1–3 张对本次造型、空间或留白有帮助的参考即可，实际构图按新场景设计。

- **极简平面型**：单一平涂天空压住大半画面，地形只留一到两条大弧或斜线，主体缩到接近剪影。`EremodiSMoro`、`MonteTomba`、`PassoMalera`、`MonteCornetto` 属此类。
- **叙事场景型**：加入云、光柱或多层山谷，体积层次更具体。`MalgaBrusa`、`MalgaPidocchio`、`MalgaBuse`、`GrottadelCiabattino` 属此类。

## 从配色想象场景

结合色相、明暗、饱和度，以及颜色之间的冷暖和对比关系，联想适合的环境、氛围与视觉焦点，再选定一个完整场景。用户已指定的地点、情绪或内容作为构思约束；其他部分由 Agent 自行想象。

例如蓝色可以启发海洋中的鲸鱼或海豚，也可以成为飞鸟掠过的天空，或冰川与细雪的冷色空间。这些只是联想示例；同一种颜色有多种解释，具体题材、主体、天气、动作和视角随整组配色与用户要求变化，示例不构成候选清单。让景物共同形成一个连贯的风景，避免为展示多种联想而堆叠无关元素。

让主色覆盖至少一个主要色面，额外指定色支持其他色面或视觉焦点，不要求等面积出现。程序推导的明暗色值仅作参考，可以按场景调整辅助色，兼顾主色辨识度、空间层次与整体美感。

将选定场景写入 `scene.description`，包含环境、主体及有需要的天气或动作；将观看位置、画面分区、主体比例和留白写入 `scene.composition`；将颜色在画面中的具体作用写入 `scene.palette_use`。这三项会进入本次生图提示词。保持简洁造型和克制细节，让每一张风景独立观看也成立。

## 审稿要点

缩到手机缩略图仍看得清主结构。检查场景是否呼应配色、主体与环境是否连贯、留白和视觉焦点是否协调；题材可以变化，简洁的系列画风应保持。检查是否出现文字、徽标、摄影光效、以光滑渐变堆砌体积、塑料材质、繁密道具或直接复刻参考图。重做前先指出是场景、构图、配色还是风格出了问题。
